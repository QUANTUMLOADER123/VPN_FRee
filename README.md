# ChromeBackground

Небольшой каркас Windows-приложения на C++17 и Win32 API. При запуске без консоли отображается сообщение «Программа уже установлена.»:

- **OK** завершает приложение.
- **Крестик** (или Alt+F4) скрывает окно и оставляет приложение работающим в фоне. Для завершения нажмите правой кнопкой мыши на значок в области уведомлений и выберите «Выход».
- **Alt+X** завершает приложение глобально, в том числе когда окно скрыто. Если сочетание уже занято или его не удаётся зарегистрировать, появится предупреждение; используйте OK или меню значка в трее.

Alt+X только завершает процесс: программа не удаляет свой файл или системные журналы. После завершения `Chrome.exe` можно удалить обычным способом.

Это демонстрационный каркас: сообщение показывается всегда и не проверяет наличие установленной программы. Фоновый процесс пока ничего не делает; приложение не устанавливает автозапуск и не является Google Chrome или VPN.

## Сборка в Windows

Понадобится Visual Studio 2022 с компонентом «Разработка классических приложений на C++» (MSVC v143 и Windows SDK). CMake не требуется.

1. Откройте `Chrome.sln` в Visual Studio.
2. Выберите конфигурацию **Release** и платформу **x64** (доступны также Debug и Win32).
3. Выберите «Сборка → Собрать решение» или нажмите **Ctrl+Shift+B**.
4. Готовый файл находится в `build\x64\Release\Chrome.exe`.

Сборка из командной строки разработчика Visual Studio:

```cmd
msbuild Chrome.sln /m /p:Configuration=Release /p:Platform=x64
```

Значок взят из [browser-logos](https://github.com/alrra/browser-logos/tree/ce0aac887b51c78c4f616adcdddfa08dbf0cd4a9/src/chrome). Chrome и его логотип являются товарными знаками Google; учитывайте права на них при распространении.
